# KRS College Connect — Football (Mercer Island High School)

College football recruiting app for Mercer Island High School players. Forked from the
KRS College Connect soccer app (Eastside FC) and converted to Division 1 football:
every FBS and FCS program, football positions, measurables and stats, Hudl-first film,
camps & combines, and coach outreach.

This is a **separate app**: its own repo, its own Supabase project, its own Vercel project.
Nothing here touches the soccer app.

## Live
- App: https://krs-football.vercel.app (Vercel project `krs-football`, deploys on every push to `main`)
- Repo: https://github.com/kirtmanpropertysolutions/krs-football

## Local setup
```
npm install
cp .env.example .env.local   # fill VITE_SUPABASE_URL and VITE_SUPABASE_PUBLISHABLE_KEY
npm run dev
```
The browser app only needs the URL and publishable key. The service-role key is not
required at runtime: signup now joins the program inside the database (see below).

## How signup works
`useAuth().signUp(email, password, inviteCode, fullName)` sends the invite code and name as
auth metadata. The `on_auth_user_created` trigger (`supabase/football/100_football_core.sql`)
validates the code, consumes one use, and creates the profile and team membership in the same
transaction. A bad code aborts the signup. The code's `role` decides athlete vs. admin.

## Database
- `supabase/schema_football_v1.sql` — the full schema for a brand-new project, generated by
  `python3 scripts/football/build-schema.py` from the inherited soccer migrations
  (minus soccer seeds and migration 031) plus `supabase/football/*.sql`.
- `supabase/football/100_football_core.sql` — everything football: athlete fields, FBS/FCS
  columns, quiz answer sets, signup trigger, admin read policies, public profile RPC.
- `supabase/football/110_seed_schools.sql` — 266 programs (138 FBS, 128 FCS) for the 2026
  season, generated from `scripts/data/football-*-2026.json` by
  `scripts/football/build-school-seed.py`. Conference membership was checked against 2026
  listings; enrollment, rank, colors and URLs are approximate.
- Test any schema change locally first: the build script also writes per-file chunks that can
  be replayed against PGlite.
